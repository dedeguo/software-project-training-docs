# 软件开发综合项目实训课程设计报告通用模板

## 使用说明

学校或教师模板优先。本模板不规定统一字数、页数、字体、章节比例或评分标准。小项目可合并小节，但应保留需求、设计、实现和测试的证据链。所有填写提示在正式提交前删除；缺失事实先保留明确标记，不能编造补齐。

任务书可独立提交，也可按学校要求放在正文前。英文摘要、致谢、独立部署章节按需增加，不默认强制。
